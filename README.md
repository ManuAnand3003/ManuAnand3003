## 🏗️ Featured Projects

### 🧠 EmoVision — Real-Time Facial Emotion Detection `IBM Internship`
> FastAPI · DeepFace · RetinaFace · ONNX · WebSockets · Vanilla JS

Real-time multi-face emotion detection from live camera and image uploads. Features a 5-frame temporal smoothing pipeline, 55/45 ONNX ensemble blending, IoU-based face tracking, and a continual learning trainer using **Elastic Weight Consolidation (EWC)** with Fisher Information Matrix to prevent catastrophic forgetting.

[![Repo](https://img.shields.io/badge/GitHub-EmoVision-181717?style=flat-square&logo=github)](https://github.com/ManuAnand3003/EmoVision)

---

### 👁 VisionCaption — AI Image Captioning System `IBM Internship`
> FastAPI · BLIP (470M params) · Vision Transformer · HuggingFace · WebSockets

Generates natural language captions for any image using Salesforce BLIP (ViT-L/16 encoder + 12-layer causal decoder). Supports beam search, nucleus sampling, greedy decode, attention heatmap visualization, and live webcam streaming with typewriter-effect captions.

[![Repo](https://img.shields.io/badge/GitHub-VisionCaption-181717?style=flat-square&logo=github)]([https://github.com/ManuAnand3003](https://github.com/ManuAnand3003/VisionCaption))

> scikit-learn · SMOTE · Streamlit · NLP

Classifies SMS/email messages as spam or ham with a modular ML pipeline. Evaluates Naive Bayes, SVM, and Random Forest — handles class imbalance using SMOTE and class weighting. Interactive Streamlit web app for real-time predictions.
